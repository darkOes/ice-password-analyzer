# ICE Password Analyzer

> Offline password strength analyzer. Nothing leaves your browser.

**▶ Live demo: https://darkoes.github.io/ice-password-analyzer/**

## Features

- Effective entropy with penalties for real attack patterns (common passwords, dictionary words, leetspeak, keyboard walks, sequences, years)`n- Crack-time estimates for 4 scenarios: throttled online, online, bcrypt offline, GPU fast hash`n- Secure random password and passphrase generator (crypto.getRandomValues)

## Notes

Estimates are approximations meant for learning, not a security guarantee.

## Tech

Single `index.html` file. Vanilla HTML, CSS and JavaScript, no dependencies, no build step. Hosted on GitHub Pages.

Run locally: open `index.html` in a browser.
